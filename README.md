## البناء

افتح المشروع في Android Studio، أو استخدم JDK 17 وAndroid SDK 36
وGradle المتوافق مع إعدادات المشروع، ونفذ Gradle assembleDebug.
يجب إعداد توقيع الإنتاج بصورة منفصلة، دون تخزين مفاتيحه في المستودع.

يتضمن الكود المصدر المشروع Android والتصميم، بعد استبعاد سجلات QA
والمفاتيح والإعدادات المحلية والنسخ الاحتياطية.
